# OctoFit Tracker (scaffold)

Frontend: Vite + React 19 (dev port 5173)
Backend: Node + Express + TypeScript (dev port 8000)
MongoDB: default port 27017 (connection: mongodb://localhost:27017/octofit)

Run (after installing deps):

Frontend:
```
cd octofit-tracker/frontend
npm install
npm run dev
```

Backend:
```
cd octofit-tracker/backend
npm install
npm run dev
```
